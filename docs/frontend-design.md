# TeamSync 前端技术报告

## 1. 目标

基于现有后端接口文档、Prisma 数据模型与项目规划，实现 `client` 前端，实现校园微团队协作系统界面，覆盖认证、项目、任务、里程碑、标签、互评、贡献度和报表等核心业务流程。

## 2. 技术选型

- 框架：React 19
- 构建工具：Vite 7
- 语言：TypeScript
- UI 组件库：Ant Design 5
- 路由：React Router
- HTTP 请求：Axios
- 日期处理：Dayjs

## 3. 前端功能实现

- 认证模块：实现注册、登录、会话持久化、退出登录
- 项目大厅：支持项目列表展示、状态筛选、标签筛选、创建项目、申请加入项目
- 标签管理：支持获取预设标签与设置个人技能标签
- 项目详情：展示项目基本信息、成员列表、里程碑、任务列表，并整合互评、贡献度与报表视图
- 成员协作：支持队长审批成员申请
- 任务协作：支持任务创建、编辑、认领、提交审核、审核通过、打回和删除
- 里程碑管理：支持新建、编辑、完成和删除里程碑
- 互评模块：支持项目关闭后提交互评、修改本人评分，并按角色区分可见数据
- 贡献度分析：支持展示成员完成任务数、任务权重和、互评均分与贡献度百分比
- 报表模块：支持展示任务状态统计、成员任务统计、互评摘要、里程碑进度、贡献度快照与 Excel 导出

## 4. 工程结构

```text
client/
├── src/
│   ├── api/          # Axios 请求封装与接口服务
│   ├── layouts/      # 页面布局
│   ├── pages/        # 登录页、项目页、详情页
│   ├── store/        # 认证状态管理
│   ├── styles/       # 全局样式
│   ├── utils/        # 日期与状态格式化
│   ├── App.tsx
│   ├── main.tsx
│   └── types.ts      # 前后端共享的数据结构定义
├── .env.example
├── index.html
├── package.json
└── vite.config.ts
```

页面说明：

- `/auth`：登录 / 注册
- `/projects`：项目大厅、个人技能标签
- `/projects/:projectId`：项目详情、任务与里程碑协作、互评、贡献度分析、报表查看与导出

## 5. 接口对接策略

- 统一通过 `Axios` 实例配置 `baseURL`
- 请求拦截器自动注入 `Authorization: Bearer <token>`
- 响应拦截器统一提取后端错误信息
- 前端表单字段和校验范围遵循后端 DTO 约束，减少无效请求
- 页面展示结构依据 `server` 实际返回字段设计
- 互评、贡献度与报表能力实现

## 6. 其他说明

- 采用 `AuthProvider` 管理登录状态，并将 token 与用户信息保存在 `localStorage`
- 项目大厅支持游客浏览，符合公开查询接口能力
- 任务状态流转在前端按业务规则限制按钮显示，避免非法操作
- 里程碑完成、成员审批等动作均直接调用后端业务接口，保证规则校验以服务端为准
- 学生端仅查看自己收到的匿名互评；教师端可查看完整互评记录
- 贡献度与报表仅在项目关闭后展示；若互评未完成，前端展示后端返回的提示信息
- Excel 导出通过浏览器 `Blob` 下载实现，不依赖额外前端插件

## 7. 结果总结

前端在于 `client` 目录，项目具备从用户认证、项目浏览、任务协作，到项目关闭后的互评、贡献度分析与报表导出的完整可视化闭环。
