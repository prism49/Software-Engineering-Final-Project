# TeamSync 前端技术报告

## 1. 目标

基于现有后端接口文档、Prisma 数据模型与项目规划，实现 `client` 前端，实现校园微团队协作系统界面，覆盖认证、项目、任务、里程碑和标签管理等核心业务流程。

## 2. 技术选型

- 框架：React 19
- 构建工具：Vite 7
- 语言：TypeScript
- UI 组件库：Ant Design 5
- 路由：React Router
- HTTP 请求：Axios
- 日期处理：Dayjs

## 3. 前端功能实现

- 认证模块：实现注册、登录、会话持久化、退出登录
- 项目大厅：支持项目列表展示、状态筛选、标签筛选、创建项目、申请加入项目
- 标签管理：支持获取预设标签与设置个人技能标签
- 项目详情：展示项目基本信息、成员列表、里程碑、任务列表
- 成员协作：支持队长审批成员申请
- 任务协作：支持任务创建、编辑、认领、提交审核、审核通过、打回和删除
- 里程碑管理：支持新建、编辑、完成和删除里程碑

## 4. 工程结构

```text
client/
├── src/
│   ├── api/          # Axios 请求封装与接口服务
│   ├── layouts/      # 页面布局
│   ├── pages/        # 登录页、项目页、详情页
│   ├── store/        # 认证状态管理
│   ├── styles/       # 全局样式
│   ├── utils/        # 日期与状态格式化
│   ├── App.tsx
│   ├── main.tsx
│   └── types.ts      # 前后端共享的数据结构定义
├── .env.example
├── index.html
├── package.json
└── vite.config.ts
```

页面说明：

- `/auth`：登录 / 注册
- `/projects`：项目大厅、个人技能标签
- `/projects/:projectId`：项目详情、任务与里程碑协作

## 5. 接口对接策略

- 统一通过 `Axios` 实例配置 `baseURL`
- 请求拦截器自动注入 `Authorization: Bearer <token>`
- 响应拦截器统一提取后端错误信息
- 前端表单字段和校验范围遵循后端 DTO 约束，减少无效请求
- 页面展示结构依据 `server` 实际返回字段设计

## 6. 其他说明

- 采用 `AuthProvider` 管理登录状态，并将 token 与用户信息保存在 `localStorage`
- 项目大厅支持游客浏览，符合公开查询接口能力
- 任务状态流转在前端按业务规则限制按钮显示，避免非法操作
- 里程碑完成、成员审批等动作均直接调用后端业务接口，保证规则校验以服务端为准

## 7. 结果总结

本次实现已补全 `client` 前端目录，使项目具备基础可视化交互能力，能够完成从用户认证、项目浏览到任务协作的核心闭环。前端结构清晰，便于后续继续扩展双盲互评、贡献度评估、报表分析和 Electron 集成等后续规划功能。
